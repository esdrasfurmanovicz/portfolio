Minha Jornada My Journey

Comecei a programar em 2021, ainda no ensino médio técnico em Análise e Desenvolvimento de Sistemas. O que começou como curiosidade virou paixão quando percebi que podia transformar ideias em soluções reais. I started programming in 2021, while in technical high school for Systems Analysis and Development. What started as curiosity became passion when I realized I could transform ideas into real solutions.

Em 2024, desenvolvi o SIF (Sistema de Irrigação Facilitado), um projeto de automação agrícola que venceu o 1º lugar na FI Ciências, uma feira internacional de inovação. Esse projeto me ensinou muito sobre trabalhar com hardware, APIs e resolver problemas reais do campo. In 2024, I developed SIF (Facilitated Irrigation System), an agricultural automation project that won 1st place at FI Ciências, an international innovation fair. This project taught me a lot about working with hardware, APIs and solving real field problems.

Em 2025, fui palestrante no FISoL (Festival Internacional de Software Livre), compartilhando conhecimento sobre desenvolvimento web. Hoje trabalho como desenvolvedor na Sismetro, onde crio e mantenho sistemas internos usando PHP/Laravel, além de continuar estudando Ciência da Computação na Uninter. In 2025, I was a speaker at FISoL (International Free Software Festival), sharing knowledge about web development. Today I work as a developer at Sismetro, where I create and maintain internal systems using PHP/Laravel, while continuing to study Computer Science at Uninter.

Minha Abordagem de Trabalho My Work Approach

Código Limpo é Prioridade Clean Code is Priority

Escrevo código pensando em quem vai manter depois. Prefiro soluções simples e diretas ao ponto do que complexidade desnecessária. Se funciona e é fácil de entender, está bom. I write code thinking about who will maintain it later. I prefer simple and straightforward solutions over unnecessary complexity. If it works and is easy to understand, it's good.

Resolvo Problemas Reais I Solve Real Problems

Não desenvolvo só por desenvolver. Cada linha de código tem um propósito: automatizar processos, economizar tempo ou melhorar a experiência do usuário. O valor está no resultado, não na tecnologia usada. I don't develop just for the sake of it. Every line of code has a purpose: automate processes, save time or improve user experience. The value is in the result, not the technology used.

Comunicação Clara Clear Communication

Traduzir termos técnicos para linguagem acessível é fundamental. Gosto de trabalhar de forma colaborativa, entender as necessidades reais do projeto e alinhar expectativas desde o início. Translating technical terms into accessible language is essential. I like to work collaboratively, understand the real needs of the project and align expectations from the start.

Aprendizado Contínuo Continuous Learning

Tecnologia muda rápido, e eu gosto disso. Sempre estou estudando, testando novas ferramentas e melhorando minhas habilidades. Perfil autodidata por natureza. Technology changes fast, and I like that. I'm always studying, testing new tools and improving my skills. Self-taught by nature.
