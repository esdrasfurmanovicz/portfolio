# Portfolio

Site pessoal de Esdras Furmanovicz, construído com Vue 3 + Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

Gera a pasta `dist/` com os arquivos estáticos prontos para publicação (GitHub Pages incluso).

## Conteúdo

Todo o texto (PT/EN) está centralizado em `src/data/content.js`: editar lá atualiza o site inteiro, sem mexer nos componentes.
